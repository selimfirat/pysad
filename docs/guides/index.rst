Overview
========

Each guide solves one task. The guides assume that you know the basic loop from :doc:`/getting_started`.

.. container:: cards

   .. container:: card

      :doc:`stream_data`

      Feed CSV files, DataFrames, message queues and benchmark datasets to a detector.

   .. container:: card

      :doc:`choose_detector`

      Find candidate detectors for your data and compare them.

   .. container:: card

      :doc:`alerts`

      Calibrate scores, choose a threshold and keep anomalies out of the model.

   .. container:: card

      :doc:`evaluate`

      Choose a metric, follow performance over time and report stable results.

   .. container:: card

      :doc:`pipelines`

      Add preprocessing, projections, postprocessing and ensembles.

   .. container:: card

      :doc:`seasonal`

      Find anomalies in metrics with a daily or weekly cycle.

   .. container:: card

      :doc:`pyod`

      Run a PyOD batch detector on a stream.

   .. container:: card

      :doc:`production`

      Start from history, save state, run one detector per source and control latency.

   .. container:: card

      :doc:`custom_model`

      Write a detector of your own and add it to PySAD.

   .. container:: card

      :doc:`/examples`

      Complete scripts that run end to end.
