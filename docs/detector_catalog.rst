Detector catalog
================

.. meta::
   :description: Catalog of every streaming detector exported by pysad.models.__all__, with its paper citation, input kind, and API link.

This page lists every streaming detector exported by ``pysad.models.__all__``. Each row links to the detector's API reference, names the paper it implements through its citation key, and gives the kind of input it takes: multivariate, univariate, timestamped, or edge. The table is rebuilt from ``pysad.models.__all__`` on every documentation build, so it always matches the library.
